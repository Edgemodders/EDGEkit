# EDGEkit

EDGEkit for Visual Studio Code: the EDGE tools for Cyberpunk 2077 modding in one install.

> **Windows x64.** REDcode and EDGEdeck work with the game's files through REDbridge, which runs on Windows only, so they install on Windows x64 only. The theme and REDscript IDE work everywhere. The pack is a preview, like REDcode and EDGEdeck.

Install this pack and you get every published EDGE extension, ready to use:

| Extension | What it does | Links |
|---|---|---|
| REDcode for Cyberpunk 2077 | A modding workspace on WolvenKit's engine: browse the game's archives, edit CR2W files, view textures, meshes and sounds, the TweakDB, pack and install WolvenKit projects | [Docs](https://edgemodders.github.io/REDcode/) · [Repo](https://github.com/Edgemodders/REDcode) · [Issues](https://github.com/Edgemodders/REDcode/issues) |
| EDGEdeck | A simple mod manager: one list of mods, add, on/off, deploy, remove, with conflicts shown even inside archives | [Docs](https://edgemodders.github.io/EDGEdeck/) · [Repo](https://github.com/Edgemodders/EDGEdeck) · [Issues](https://github.com/Edgemodders/EDGEdeck/issues) |
| REDnode HUD | A dark theme in the REDnode house style | [REDnode docs](https://edgemodders.github.io/REDnode/) · [Repo](https://github.com/Edgemodders/REDcode/tree/main/extensions/rednode-hud-theme) · [Issues](https://github.com/Edgemodders/REDcode/issues) |
| REDscript IDE, by jac3km4 | Redscript language support. On the Marketplace only, so not in this pack on Open VSX | [Docs](https://github.com/jac3km4/redscript-ide-vscode#readme) · [Repo](https://github.com/jac3km4/redscript-ide-vscode) · [Issues](https://github.com/jac3km4/redscript-ide-vscode/issues) |

New EDGE extensions join the pack as they are published. Uninstalling the pack offers to remove them too; each one can also be kept or removed on its own.

**EDGEkit is also an editor:** a build of Code - OSS with all of this built in, for modders who want one app. See the [EDGEkit docs](https://edgemodders.github.io/EDGEkit/) and [repo](https://github.com/Edgemodders/EDGEkit).
