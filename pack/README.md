# EDGEkit

EDGEkit for Visual Studio Code: the EDGE tools for Cyberpunk 2077 modding in one install.

Install this pack and you get every published EDGE extension, ready to use:

| Extension | What it does |
|---|---|
| [REDcode for Cyberpunk 2077](https://github.com/Edgemodders/REDcode) | A modding workspace on WolvenKit's engine: browse the game's archives, edit CR2W files, view textures, meshes and sounds, pack and install WolvenKit projects |
| [REDdeck](https://github.com/Edgemodders/REDdeck) | A simple mod manager: one list of mods, add, on/off, deploy, remove, with conflicts shown even inside archives |
| [REDnode HUD](https://github.com/Edgemodders/REDcode) | A dark theme in the REDnode house style |
| [Redscript IDE](https://github.com/jac3km4/redscript-ide-vscode) | Redscript language support, by jac3km4. On the Marketplace only, so not in this pack on Open VSX |

New EDGE extensions join the pack as they are published. Uninstalling the pack offers to remove them too; each one can also be kept or removed on its own.

**EDGEkit is also an editor:** a build of Code - OSS with all of this built in, for modders who want one app. See [EDGEkit](https://edgemodders.github.io/EDGEkit/).
